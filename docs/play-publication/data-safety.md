# Безопасность данных (форма Data safety)

Ответы выведены из кода Android-приложения 0.5.10 и сервера. Всё, что отмечено ⚠, владелец
подтверждает перед отправкой формы: это заявление Google от его имени.

## Общие вопросы

| Вопрос | Ответ | Основание |
|--------|-------|-----------|
| Собирает ли приложение данные пользователей | Да | время смен, имя, данные для входа |
| Передаются ли данные третьим лицам («sharing») | Нет | Sentry получает отчёты об ошибках как обработчик (service provider), это не «передача» по определению Google ⚠ |
| Шифрование при передаче | Да | HTTPS ко всем запросам |
| Можно ли запросить удаление данных | Да | через администрацию работодателя или e-mail ⚠ `{{CONTACT_EMAIL}}` |

## Типы данных

Приложение запрашивает только `INTERNET`, `NFC`, `ACCESS_NETWORK_STATE`, `POST_NOTIFICATIONS`,
`RECEIVE_BOOT_COMPLETED`. Геолокации, контактов, фото, микрофона, рекламного ID нет.

| Категория Play | Тип | Собирается | Обязательно | Цель | Заметка |
|----------------|-----|------------|-------------|------|---------|
| Личная информация | Имя | Да | Да | Функциональность приложения, управление аккаунтом | имя работника задаёт работодатель |
| Личная информация | Идентификаторы пользователя | Да | Да | Функциональность приложения | внутренний номер работника, токен сессии |
| Личная информация | Адрес электронной почты | Да, необязательно | Нет | Управление аккаунтом | только если включён вход по e-mail (флаг `email_login`, сейчас выкл.) ⚠ |
| Личная информация | Номер телефона | Да, необязательно | Нет | Управление аккаунтом | только при входе по SMS (флаг `sms_login`, сейчас выкл.) ⚠ |
| Действия в приложении | Действия в приложении / другой созданный пользователем контент | Да | Да | Функциональность приложения | начало и конец смены, метка NFC-тега, заявки на материалы, заметки к смене |
| Информация о приложении и его производительности | Журналы сбоев | Да | Да | Аналитика (стабильность) | Sentry, без `sendDefaultPii`, поля очищает `Scrub.kt` |
| Информация о приложении и его производительности | Диагностика | Да | Да | Аналитика (стабильность) | трейсы Sentry, версия приложения |
| Идентификаторы устройства или другие | — | ⚠ проверить | — | — | Sentry создаёт случайный идентификатор установки; если подтвердится, отметить как собираемый, не привязанный к личности |

Служебные заголовки телефона (число несинхронизированных смен, время последней связи) хранятся
на сервере у работника, цель «функциональность приложения»; отдельного типа данных в форме для
них нет, они попадают под «Действия в приложении».

## Что НЕ собирается

Точное и примерное местоположение, контакты, сообщения (SMS не читаются, только отправляются
сервером при включённом входе), фото и видео, аудио, файлы, календарь, здоровье, финансовая
информация, история веб-поиска, рекламный ID.
