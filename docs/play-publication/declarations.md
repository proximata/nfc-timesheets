## Доступ к приложению

Google требует рабочий вход для проверяющего. Вход в приложение возможен только по
**одноразовому коду доступа** (5 цифр), который выпускает администратор, и код истекает. Для
проверки нужно:

1. создать отдельную компанию-демо (или учебного работника) на staging-API;
2. дать проверяющему инструкцию: «Введите код доступа», с кодом, который будет жить в момент
   проверки (может потребоваться несколько дней);
3. либо договориться с Google через поле инструкций («свяжитесь с нами на `{{CONTACT_EMAIL}}`,
   пришлём код»). Это допускается, если ответ быстрый.

Предложение: завести учебного работника «Google Review», перед отправкой выпуска на проверку
выпустить ему свежий код и написать его в поле «Доступ к приложению» вместе с шагами; при
повторной проверке выпускать новый. Продление срока жизни кода для учебного аккаунта потребует
изменения на сервере: решает владелец.

## Разрешения

| Разрешение | Зачем |
|------------|-------|
| `NFC` | читать метки на объекте |
| `INTERNET`, `ACCESS_NETWORK_STATE` | синхронизация смен |
| `POST_NOTIFICATIONS` | показать идущую смену и напомнить об окончании |
| `RECEIVE_BOOT_COMPLETED` | вернуть уведомление идущей смены после перезагрузки |

Ограниченных разрешений (геолокация, SMS, журнал вызовов) нет. Foreground-сервиса нет.
